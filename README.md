# LearningPlaywrightBatch

Small Playwright practice repository used for learning and exercises.

## Quickstart

Prerequisites:
- Node.js (v14+)
- npm or yarn

Install dependencies (if you add any):

```bash
npm install
# or
yarn install
```

Run Playwright tests (if configured):

```bash
npx playwright test
```
